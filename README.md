## About this project

MOSAD is a self-hosted local app to search YouTube Music, build playlists, edit song metadata and download your music as high-quality MP3 files — all from your browser, with no account, no database and no tracking.

Playlists are stored as JSON files on your own machine. Everything stays local.

## Installation

```bash
pip install -r requirements.txt
```

> Make sure `ffmpeg` is installed on your system. It is required by yt-dlp to convert audio to MP3.
> ```bash
> # Fedora
> sudo dnf install ffmpeg
> # Ubuntu/Debian
> sudo apt install ffmpeg
> # macOS
> brew install ffmpeg
> ```

## Usage

```bash
python app.py
```

Then open in your browser: **http://localhost:5001**

1. From the homepage, choose **Singles** or **Playlists**.
2. In **Singles**, search for a track, confirm the metadata and download it as MP3.
3. In **Playlists**, create or import a playlist, add songs, reorder them by dragging, and download the full playlist.

Files are saved under `downloads/singles/` for individual songs and `downloads/playlists/` for playlist downloads.

## Notes

- Playlist data is stored as JSON files in `playlists-data/`. Each file has a `mosad-playlist-json` header for validation.
- Importing a JSON that was not generated by MOSAD will be rejected.
- No data is ever sent to any server other than YouTube (via yt-dlp).
- MP3 files are exported in `kebab-case`: `artist-title.mp3`.
